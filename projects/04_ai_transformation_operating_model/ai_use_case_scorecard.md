# AI Use-Case Scorecard

Score 1–5.

| Dimension | Question |
|---|---|
| Strategic value | Does the use case matter to a priority outcome? |
| AI advantage | Is AI meaningfully better than rules/process redesign alone? |
| Data readiness | Is the required data available, reliable, and timely? |
| Model feasibility | Is the task technically tractable? |
| Workflow fit | Can the output change an actual decision or action? |
| Adoption readiness | Will users trust and use it? |
| Value potential | Is the quantified benefit material? |
| Time to impact | Can evidence be generated quickly? |
| Governance complexity | Can risk be controlled? |
| Scalability | Can the capability extend beyond one pilot? |

Do not use the score as an automatic investment decision. Use it to structure the leadership debate and expose assumptions.
